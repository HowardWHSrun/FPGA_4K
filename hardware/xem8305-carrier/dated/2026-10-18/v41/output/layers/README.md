# Native V41 copper and silkscreen plots

Read-only KiCad 10.0.6 SVG exports of the public V41 review PCB, using the saved zone fills. Each plot includes Edge.Cuts. All views look down from the top; the bottom layers are not mirrored. Open the SVG at full size to inspect tracks, pads, vias and plane outlines. Plots show geometry, not a simulation of return current or signal integrity.
