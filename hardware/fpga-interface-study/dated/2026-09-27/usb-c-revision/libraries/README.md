# Project library sources

27 September 2026. Keep these libraries with the project.

The KiCad-derived symbol and footprint subset is credited to the KiCad library contributors. Its original identifiers are retained in the component manifest's `source_lib_id` and `source_footprint` fields. Project-local names, reviewed pin types, geometry and footprint filters may differ from upstream. The included [upstream license](KiCad_Library_LICENSE.md) applies to that library material; it does not declare a license for unrelated project files.

Upstream: [symbols](https://gitlab.com/kicad/libraries/kicad-symbols), [footprints](https://gitlab.com/kicad/libraries/kicad-footprints), and [licensing explanation](https://www.kicad.org/libraries/license/). The license file was retrieved unchanged from the official footprint repository on 27 September 2026.

New component-specific lands and symbols were prepared for this development revision from the manufacturer drawings linked in the component manifest and interface/power reviews. Their presence does not establish assembly acceptance or electrical qualification. Referenced standard 3D models require the corresponding installed KiCad libraries; missing models must not be interpreted as available mechanical space.
