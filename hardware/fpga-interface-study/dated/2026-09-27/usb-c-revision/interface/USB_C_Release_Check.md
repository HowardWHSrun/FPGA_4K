# USB-C revision: what still prevents release

27 September 2026. This review refers to the **33 × 36 mm USB-C revision**, not the earlier micro-HDMI board. No board has been ordered, powered or demonstrated by this work.

The current schematic has been checked against the component pin maps: 179 component footprints, all 116 digital ASIC signal assignments, the separate external AC_IN analog connection, and four bank-16 LVDS pairs. The latest independent check found no unexpected pin-map changes or interface MPN/footprint mismatches; native ERC has zero errors and one intentional warning for the externally supplied AC_IN signal. These are schematic checks, not proof that the new PCB is routed or operational. See [the source-bound audit](evidence/Native_USB_Interface_Audit.json).

## Why the new parts are necessary

The **STM32 controller and its always-on supply** negotiate power and provide programming/recovery while the FPGA is blank. The **CC protector and protected main-power switch** handle connector faults and control the large input-capacitor charging load. The **orientation mux** makes all four differential pairs usable with either plug orientation; its powered-off I/O rating addresses an actual back-power risk. The **JTAG translator** connects 3.3 V controller signals to the FPGA’s 1.8 V configuration domain. The **three ESD arrays** protect exposed data conductors. The five SWD contacts are bare copper for initial controller programming and recovery; they are not another fitted connector. Local bypass capacitors remain required even where the board looks empty.

## Concrete release blockers

| Owner | Work still required | Evidence that closes it |
|---|---|---|
| PCB/layout owners | Finish the USB-C power/control/data routes and reconcile all component moves in one native board. Source-bound routing handoffs record any reopened flash, control or capacitor branch for reconstruction; the final board must close these explicitly. The compact 64 Mbit USON flash is now selected in the development schematic and placement; its new routes, central-metal keepout and assembly process remain unqualified. | One frozen PCB matching the final schematic/manifest; native zero shorts/clearance faults and zero unintended opens; explicit NC inventory; independent physical-pad/via and retained-net audit. |
| Firmware + receiver owners | Implement the STM32 CC/PD/USB2/JTAG state machine, FPGA link logic and matching receiver adapter. The XEM8310’s existing USB port is not a USB host for this headboard. Blank-FPGA recovery has a hardware path, but no working controller image or Artix bitstream is supplied. | Factory SWD recovery, safe default attachment, unsupported-host behavior, JTAG configuration, all four plug-orientation combinations and end-to-end captures demonstrated with the actual receiver. |
| ASIC/FPGA owners, using Gerald/Jiaao’s specification | Finalize SPI words, reset polarity/pulse widths, outgoing clock ownership/rate, returned-clock timing and valid-data framing. AC_IN needs its external 0–1.5 V analog source. The current schematic cannot establish the ASIC’s timing requirements. | An agreed chip-revision-specific startup/capture contract and measured captures. Approximately 2 Gbit/s is a planning target; 2.56 Gbit/s is the conservative raw-data scenario, not a measured demand. |
| Power/bring-up owner | Check 5 V cold attachment, requested operating contract, inrush/PG behavior, disconnect/brownout, CC faults and converter/eFuse/LDO/MOSFET temperatures with the actual load and cable. Capacitor DC-bias curves are typical data, not guaranteed effective capacitance. | Rail sequencing, minimum rail voltages, ripple, current-limit behavior, input droop and temperature measurements over the intended loads and cable conditions. No present 3 A or thermal scenario is an operating guarantee. |
| PCB/FPGA/receiver owners | Route each data/clock pair with coupled topology, appropriate return paths and recorded skew. Determine geometry for the selected 12-layer construction and cable; full-channel LVDS timing remains unqualified. | Pair/layer/via/length report bound to the final board, accepted impedance geometry or coupons, implemented timing closure and eye/error-rate tests at the selected rate. No 900 Mbit/s-per-lane guarantee is made. |
| Fabrication/assembly reviewer | Accept the actual 12-layer stack, BGA/0402 process, connector shell slots/tail engagement, and any adopted floating-exposed-metal USON keepout/paste plan. | Fabrication/assembly review of final files before an authorized order, followed by inspection and continuity/bring-up checks. The manufacturer has not accepted this design and no order is authorized. |
