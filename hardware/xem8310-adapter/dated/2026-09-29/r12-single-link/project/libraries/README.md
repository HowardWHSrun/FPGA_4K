# R12 project libraries

AdapterR12 symbols are the newly generated single-link study. AdapterR8 stack footprints are preserved source-derived connector land patterns; AdapterR11 contains the TI RPW0010A candidate land pattern. Their footprint and mating qualification remain open.

The standard footprint subset is copied unchanged from the installed KiCad 10.0.6 libraries. See [KiCad library license](KiCad_Library_LICENSE.md) and [upstream library sources](https://gitlab.com/kicad/libraries/kicad-footprints). Only used footprints are bundled. Standard 3D bodies refer to the user's installed `KICAD10_3DMODEL_DIR`; custom stack connector bodies are absent. Library tables are project-relative.
