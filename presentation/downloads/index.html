Where each power rail goes

RailConnectionPurpose
12 VBarrel input → XEM MC1 VDCINMain power for the XEM8305
3.3 VCarrier converter → JP1 → LDO J1 pins 1/2Power input to the LDO/ASIC assembly
1.8 VXEM module output → FPGA VCCO pinsFPGA I/O-bank supply

The XEM's main input receives 12 V. The separate 3.3 V converter feeds the LDO/ASIC assembly. Opal Kelly specifies a 5–15 V XEM input and recommends 12 V; official power documentation also explains the module-provided 1.8 V bank supply.
