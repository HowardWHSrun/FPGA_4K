Reusable PCB review · template

Meeting date · review focus

Template only. Replace prompts with dated evidence before publishing a meeting.

01 / Overview

What changed since the last review?

List the main progress, today’s objective and blockers. Link the previous meeting.

02 / PCB status

Board status

Use the same board order: ASIC / carriers → routing / LDO → FPGA → downstream / PC.

For each: owner, revision, change since last review, evidence or checks, and next step. State “no update supplied” where appropriate.

03 / Interfaces

System and interfaces

Show the current dated diagram. Review signals / clocks, data / commands, power and mechanical constraints. Identify which links changed.

04 / Decisions

Decisions to close

List each decision, options, evidence, owner and outcome. Separate proposed, open and approved items. Carry unresolved decisions forward with their original date.

05 / Actions

Owners and next steps

Record action, owner, due date, status and completion evidence. Use TBD for missing dates or owners; never infer completion.

06 / Sources

Meeting record and evidence

Link unchanged original notes, diagrams, design revision and dated check reports. Keep detailed discussion here.
