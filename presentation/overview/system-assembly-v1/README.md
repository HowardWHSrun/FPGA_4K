# System assembly overview V1

Restores the earlier interactive system overview on 1 November 2026. Whole-system, frontend-stack, HDMI Extension Board/XEM8310, PC/PCIe, individual-link and stack-separation controls are retained. Display names use the current board names.

Geometry and rendering dependencies are reused from the preserved [28 October system viewer](../../meetings/2026-10-28-v8/assets/system-viewer/index.html). See its [model provenance](../../meetings/2026-10-28-v8/assets/system-viewer/PROVENANCE.md) and [ASIC details](../../meetings/2026-10-28-v8/assets/system-viewer/ASIC_MODEL_V5.md). This wrapper changes display names and paths; it does not change the geometry, registrations, connection endpoints or CAD.

The overview remains an assembly concept with earlier model snapshots (frontend V60, separate LDO V13, retained HDMI/host geometry). Dimensions, spacing, cable paths and fit remain illustrative. The three current V6 board pages and complete KiCad ZIPs are linked separately in the [main overview](../../../?approach=custom). Those individual board views use the published current files.
