MODEL NOTES / v0.1

A presentation model,
not a fabrication release.

The opening scene is derived from the repository’s preserved stacked_headboard_original.stl. A identifies the ASIC-carrier stack, B+C the routing PCB, and D the FPGA PCB. These roles come from the assembly guide; the STL contains geometry only.

What was shortened?

The earlier shortened-bridge file was not present in the repository or available files. This starter therefore contains a new, explicitly provisional visualization study. It shortens the connecting span along X from 15 to 5 model units, keeping the carrier stack fixed and translating the right-hand boards without scaling them. This is not a selected smaller connector footprint, a verified clearance, or the team’s confirmed prior revision.

The source STL does not specify physical units. Neither these numbers nor the displayed geometry should be treated as final millimeter dimensions. The original model’s author is unverified.

Adjust the discussion study

Default 5 is a presentation assumption, not a requested dimension. “Original” restores all original positions. No native PCB files have been changed.

Scope for the next iteration

This is the shared opening and navigation scaffold. Component choices, electrical interfaces, routing progress, testing, and PI decisions will be added from the team’s supplied content. KR260 and PC are outside this CAD model; the footer shows the intended functional path only.
