System overview

Model provenance and presentation scope

Approach B now shows the 26 October Carrier V1 from-scratch revision. All 80 native component-body model assignments resolve and were visually checked. The public rotatable assembly adds XEM8305 and original LDO geometry using freshly checked connector datums and nominal mating gaps. Public body geometry is independently authored; supplier model files remain local. Native CAD checks are scoped to the saved project rules. Verification summary · Model scope and open qualification. The earlier V42 overview is preserved.

Approach A’s Overview shows the V23 assembly study: same-facing ASIC board concepts, flat LDO V13, FPGA V54 and the separate BRK8305 / interposer V12 placement snapshot / XEM8305 host. One timeline seats each assembly; sheep context is optional. Public connector previews are project-authored nominal geometry with supplier references, while exact supplier CAD remains local. ASIC pass-through redesign, populated fit and hardware operation remain unqualified. See V23 model coverage, source revisions and omissions.

The native subsystem sections retain their saved FPGA V41, LDO V5/combined V7 and host V4 checkpoints. Their preserved model sources and transforms remain available. The V5 overview preserves the earlier assembly and September adapter study.

The original 650-triangle STL remains preserved byte for byte in the repository and earlier overviews.
