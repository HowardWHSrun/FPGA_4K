THREE-PORT RECEIVER PATH · 29 SEPTEMBER

Three FPGA boards → three cables → interposer → XEM8310

See 3D stack and exact pins →
ASIC routing split TBD→3 × XC7A25T↔3 × µHDMI↔interposer routing study↔XEM8310 / BRK8310→USB / PC

Each FPGA has two active recording pairs, a wired but reserved third pair, and one reverse control pair. The proposed interposer assigns one XEM GTY bank to each cable. All three links are intended to run together over XEM USB. BRK J6 PCIe is a later alternate mode because its GTY lanes are used by two cables. The three protected 12 V cable branches, physical fit and link performance still need engineering proof.

System overview

Model provenance and presentation scope

The supplied stacked_headboard_compact_B_v1(1).stl is preserved byte for byte. The browser uses all 650 source triangles. Camera animation changes the view, not the model.

The former B bridge region and C lower board are grouped as one routing/LDO subsystem per Howard’s September 22 instruction. The source model is not edited. The overview receiver stack is an explanatory drawing; the adapter detail view uses derived Opal Kelly XEM8310 and BRK8310 models and labels the proposed interposer separately. Neither view proves mating fit. The R2 direct-carrier option and earlier KR260 concept remain in dated history.

Names are reported workstream assignments from the repository’s September 18 follow-up. They do not replace its separate, still-unassigned layout reservation and reviewer records.
